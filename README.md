# 自然灾害预警系统

[English](README.en.md) · [打开网站](https://geowarning.cn/)

查看灾害报告与应急准备资料的静态网站，适用于手机和电脑。界面支持中文、英语、西班牙语、法语和意大利语。可在主页切换浅色或深色主题，浏览器会记住选择。

## 主要功能

| 页面 | 功能 |
| --- | --- |
| 总览 | 浏览中国预警与全球地震概况，点击概览卡片可查看相关记录。 |
| 中国 | 按省、市、区县查看。点击预览地图或大图中的城市圆点，直接跳转到当地预警。点击「打开大图」可放大浏览。预警详情包含影响区域、防御要点，以及可获取的官方原文。次生灾害以定性提示呈现。 |
| 全球灾害 | 在世界地图上浏览地震与 GDACS 报告，按灾害类型筛选，或打开「查看全部当前灾害」搜索记录。地图下方的事件列表与详情列表均按报告更新时间排列 GDACS 事件。震级以琥珀色到红色区分。 |
| 美国天气预警 | 按州或属地查询美国国家气象局（NWS）通报，可展开查看发布机构、发布时间、到期时间、影响地区及原文指示。 |
| 数据来源与覆盖范围 | 查阅各数据源的覆盖地区、采集频率、报告解读及官方链接。 |
| 数据库与救援联系 | 浏览已收集的历史记录，按国家或地区查找救援机构或官方目录。 |
| 指南、工具与互动演练 | 查阅防御指南，使用急救步骤卡、应急物资清单及家庭应急计划，体验互动演示。 |
| 设置 | 调整语言、文字大小、对比度、动效和浏览器提醒。 |

## 数据来源与更新

中国预警、全球地震与 GDACS 数据由 GitHub Actions 定时采集，已发布的快照由 GitHub Pages 提供。日常浏览及本地开发均无需 API 密钥。

- **美国天气预警：** 此页面联网直接查询 NWS 有效预警接口，打开时查询，保持可见时每两分钟更新。每次最多展示 40 条符合条件的消息，并链接至 NWS 官方地图。[NWS 接口说明](https://www.weather.gov/documentation/services-web-api)
- **中国气象预警：** 来自中国气象局授权的 WeatherCN 数据服务。上游数据按城市提供，区县筛选依据官方正文中的地名。未细分区县的预警可能适用于全市。采集任务轮换覆盖 77 个已配置城市，通常每 15 分钟查询 4 个城市，滚动 24 小时最多尝试 450 次。独立的实况天气读数可能使用 Open-Meteo。
- **全球灾害：** 使用 GDACS 当前事件报告，辅以其搜索接口提供的详情。采集计划每五分钟运行一次。全球灾害地图面板和实时灾害列表在页面可见时每分钟检查发布更新。GitHub Actions 的调度和发布可能延迟。
- **地震：** 配置 APIZERO 时优先使用该来源，失败或未配置时使用美国地质调查局（USGS）。采集计划每 15 分钟运行一次。
- **历史记录与救援联系：** 档案保留本项目已收集的记录。救援目录提供已收录机构和公开联系资料，不提供调度服务，也不核实机构当前是否可用。

「刷新已发布数据」会重新下载最新快照。中国页面和大图中的「更新数据」会打开 GitHub 申请表单。登录并提交后可申请采集，仍受共享配额和冷却时间限制。部署、配额和 GitHub Actions 密钥的说明见[采集与部署指南](backend/README.md)。

## 如何理解延迟或缺失的数据

中国地图保留上次成功查询的原始时间和结果。绿色表示当时无预警，黄色表示当时有预警，红色表示当时包含红色预警。虚线环表示历史结果，例如中国预警数据已超过六小时。灰色表示没有历史结果。

GDACS 更新逾期时，虚线标记显示上次报告的位置，当前状态尚未确认。历史记录或空白列表均不能证明当地安全。请遵循当地主管部门发布的最新指示，遇紧急情况请拨打当地紧急电话。

联网访问后，可在同一浏览器离线阅读安全指南。浏览器提醒只在页面打开时检查，不能替代官方紧急通知。设置中的快照下载次数仅统计当前浏览器的尝试，包含失败。

## 本地运行

使用 Python 3 通过 HTTP 提供静态文件。在仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。本地网站使用仓库内已发布的快照，数据可能过期。无需编译或安装项目依赖。

使用 Node.js 22 或更新版本运行检查：

```sh
node --test backend/*.test.mjs
```

如需验证发布准备流程和生成搜索索引，可以将公开文件复制到临时目录后运行，避免修改受 Git 跟踪的文件：

```sh
site="$(mktemp -d)"
cp -R index.html CNAME favicon.svg sw.js manifest.webmanifest robots.txt sitemap.xml css js assets public-data "$site/"
ALLOW_STALE_DATA=1 node backend/prepare-site.mjs "$site"
python3 -m http.server 8000 --directory "$site"
```

## 仓库结构

- `index.html`、`css/`、`js/` 和 `assets/`：静态网站文件。
- `public-data/`：已发布的预警、灾害记录和目录数据。
- `backend/`：数据采集、测试与发布准备脚本。
- `.github/workflows/`：定时采集和 GitHub Pages 发布流程。
